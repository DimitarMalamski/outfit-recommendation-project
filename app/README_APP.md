# Runway AI Stylist Application

This folder contains the final transferable prototype for the Outfit Recommendation System.

The application is split into two parts:

- `frontend/` contains the Next.js user interface.
- `backend/` contains the FastAPI AI inference API.

The prototype allows a user to upload a clothing image and receive a complete outfit recommendation based on:

- style classification
- clothing type classification
- CLIP-based recommendation ranking
- confidence-based reliability feedback
