I am working on a machine learning project called Outfit Recommendation System.

The system recommends clothing items based on an input clothing image. The current pipeline works like this:

1. Predict the style of the input item.
2. Predict the clothing type of the input item.
3. Filter the recommendation catalogue to items with the same predicted style.
4. Exclude items with the same predicted clothing type.
5. Rank the remaining candidate items using image embeddings and cosine similarity.
6. Return one recommended item per remaining clothing type.

The project uses four style classes:

- formal
- gothic
- sporty
- streetwear

The project uses four clothing type classes:

- jacket
- pants
- shoes
- tshirt

The current recommendation catalogue is stored in:

../dataset/cleaned

The real-world test set is stored in:

../dataset/real_world_test

The real-world test set structure is:

real_world_test/style/type/image

For example:

real_world_test/streetwear/jacket/streetwear_jacket_rw_001.png

This means:

true style = streetwear
true type = jacket

Important: the real-world test set is evaluation-only and must not be used for training.

Based on teacher feedback, I then compared different model architectures for style classification:

- ResNet34
- MobileNetV3 Large
- EfficientNet-B0

All models were trained with the same improved style training setup:

split_style/train + style_extra

They were evaluated on the same curated test set and the same real-world test set.

The architecture comparison results were:

ResNet34:
Curated accuracy: 0.7833
Curated macro F1: 0.7777
Real-world accuracy: 0.5875
Real-world macro F1: 0.5898
Model size: 81.34 MB

MobileNetV3 Large:
Curated accuracy: 0.8167
Curated macro F1: 0.8105
Real-world accuracy: 0.6250
Real-world macro F1: 0.6242
Model size: 16.25 MB

EfficientNet-B0:
Curated accuracy: 0.8417
Curated macro F1: 0.8422
Real-world accuracy: 0.5500
Real-world macro F1: 0.5541
Model size: 15.60 MB

Conclusion from the architecture comparison:

- MobileNetV3 Large had the best real-world style classification performance.
- EfficientNet-B0 had the best curated test accuracy but the worst real-world accuracy.
- This confirmed that curated accuracy does not automatically mean better real-world generalization.
- MobileNetV3 Large became the best candidate style model.

Then MobileNetV3 Large was tested inside the full recommendation pipeline.

Conclusion:

MobileNetV3 Large should replace the previous ResNet34 style classifier in the current prototype. It improved both automatic style accuracy and manual recommendation quality. However, the improvement is moderate. Visual coherence is still weaker than structural validity, meaning the system usually recommends the correct clothing categories, but the selected items do not always form the best-looking outfit.
